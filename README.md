# Discord Middleman Bot
### Overview
Complete Middleman discord Bot

You can host it as a web service.

### Features included:
- **Server switching**
- **Owner always online**
- **Staff Whitelisting**: owners can easely manage staff to help you.
- **Staff panel**: the staff will have access to a channel with buttons to manage the server.
- **Deal management**: the bot creates new wallets for every payment invoice, all the private keys are sent to the owner account, confirming the release of the money will kick the non-staff member from the server.
- **Auto-detection of transactions**: the bot auto-detects the transactions making it easy to use.
- **Fake transactions**: the bot DMs the staff member of the deal with a panel.
